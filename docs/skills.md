# Optional agent skills

Skills are optional capabilities, not mandatory project tooling or a bulk setup
requirement. Developers may install selected useful skills in their own agent
environment. Read the installed skill's instructions when using it.

The following 40 skill directories are retained at `~/.agents/skills`.
**Installed*** is an approved retention label: it records a local installation,
not a verified publisher, upstream source, version or endorsement.
**Published provenance is UNKNOWN** for every entry; this catalogue provides no
fictional upstream installation URLs and copies none of these skills into Home.

## Repository and global scope

Dataportal retains `.agents/skills/playwright-cli/SKILL.md` and all nine
`references/*.md` files as one repository-scoped skill. Its published origin
is unverified. Executable resolution and localhost-only browser restrictions
remain in Dataportal's local agent guidance; shared recommendations do not
broaden them.

`~/.config/opencode/AGENTS.md` remains global OpenCode guidance. It is neither
copied into this repository nor replaced with a repository-scoped pointer.
Existing user-level skill folders and global instructions remain untouched.
