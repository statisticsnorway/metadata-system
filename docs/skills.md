# Optional agent skills

Skills are optional capabilities, not mandatory project tooling or a bulk setup
requirement. Developers can choose tools that fit their work and agent
environment. This note is intentionally non-exhaustive: local installations do
not establish team relevance, published origin or endorsement.

- **Archify** can help create and maintain the repository's source-backed
  diagrams. The diagram workflow and committed artifacts are described in the
  [Home page](index.md#diagrams).
- **Playwright CLI** is a repository-scoped skill retained in Dataportal at
  `.agents/skills/playwright-cli/`, with its nine reference files. Its local
  guidance restricts browser access to that project's localhost server.

No publisher or installation source is asserted here. This catalogue does not
copy, install or remove skills from developer environments.

## Repository and global scope

Dataportal's executable resolution and localhost-only browser restrictions
remain in its local agent guidance; shared recommendations do not broaden them.
Developer-level skills and global agent instructions retain their existing
scope and are not catalogued here.
